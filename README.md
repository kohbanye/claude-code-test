# claude-code-test

Claude Code を試すためのテスト用リポジトリです。

## 概要

このリポジトリは、Claude Code の動作確認や実験のために作成されました。
特定の目的を持ったプロジェクトではなく、自由に試すためのサンドボックスとして利用できます。

## 使い方

```bash
# リポジトリをクローン
git clone https://github.com/kohbanye/claude-code-test.git
cd claude-code-test
```

あとは好きなようにファイルを追加したり、Claude Code に作業を依頼したりしてください。

## 主な用途

- Claude Code の各種機能や設定を試す
- プロンプトやワークフローの検証
- Git 連携（ブランチ運用・PR 作成）の動作確認
